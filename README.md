## What this is

Exactly one word, the first that comes to mind:

> fireflies

A small warm light you only notice on a quiet night. No topic, no explanation, no second draft.

## How it works

`main.py` (Python 3, no network, deterministic) writes the word to `/output/entry.txt`.

```bash
python3 main.py
```
